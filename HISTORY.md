# Version history

This history was reconstructed on 2026-10-13 from the saved source snapshots in the game-development conversation. The ordering follows the available game versions. The commit dates describe this import, not original development dates, and the import author is a placeholder rather than a claim of authorship.

The earlier EconForge idea is preserved at `reference-econforge`; the game then evolves through BusinessGame and TranslateUni. Every snapshot has an annotated tag. Select a tag on GitHub to browse or download that version. Local example: `git switch --detach v6.2`; return with `git switch main`.

Source, project/solution files, course data, scripts, documentation and the third-party license are included. Compiled binaries, runtime save data, actual online invitations, caches, screenshots and temporary development tools are excluded. Source files were checked against their saved snapshots using Git object hashes.
